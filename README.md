# Django Models Admin Homework

Домашнее задание по Django ORM, моделям, панели администрирования и расширению пользовательской модели.

## Описание

Проект реализует небольшую систему учёта сотрудников, их навыков и рабочих мест.

В проекте созданы два приложения:

- `employees` — сотрудники и навыки;
- `workplaces` — рабочие места.

Через панель администрирования Django можно добавлять, изменять и удалять сотрудников, навыки, уровни владения навыками и рабочие места.

## Возможности

В проекте реализовано:

- расширение стандартной пользовательской модели Django;
- модель сотрудника;
- модель навыка;
- модель связи сотрудника и навыка с уровнем освоения от 1 до 10;
- модель рабочего места;
- связь один-к-одному между сотрудником и рабочим местом;
- регистрация всех моделей в панели администрирования;
- миграции для созданных моделей;
- форматирование кода по стилю Django.

## Модели

### Employee

Кастомная модель сотрудника, расширяющая стандартную модель пользователя Django.

Содержит:

- имя;
- фамилию;
- отчество;
- пол;
- описание;
- связь с навыками.

### Skill

Модель навыка сотрудника.

Примеры навыков:

- Backend;
- Frontend;
- Testing;
- Project management.

### EmployeeSkill

Промежуточная модель для связи сотрудника и навыка.

Содержит:

- сотрудника;
- навык;
- уровень освоения навыка от 1 до 10.

### Workplace

Модель рабочего места.

Содержит:

- номер стола;
- сотрудника;
- дополнительную информацию.

Между рабочим местом и сотрудником создана связь один-к-одному.

## Панель администрирования

В админке зарегистрированы модели:

- Сотрудники;
- Навыки;
- Навыки сотрудников;
- Рабочие места.

Админ-панель доступна по адресу:

```text
http://127.0.0.1:8000/admin/
```

## Установка и запуск

1. Создать виртуальное окружение:

```bash
py -m venv .venv
```

2. Активировать виртуальное окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Применить миграции:

```bash
python manage.py migrate
```

5. Создать суперпользователя:

```bash
python manage.py createsuperuser
```

6. Запустить сервер:

```bash
python manage.py runserver
```

7. Открыть админку:

```text
http://127.0.0.1:8000/admin/
```
